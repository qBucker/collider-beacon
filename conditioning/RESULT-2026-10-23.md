## Interpretation

- Conditioning removes the structural raw-stream flags. The conditioned stream
  sits at the statistical noise floor: one borderline template line in one of
  eight conditioned runs, and no ApproximateEntropy or uniformity flags.
- 25,000 events (300,000 bits) is the recommended default. It is about 3,500
  storage-floor comb periods (the comb period is ~85 bits), so the block is
  still large compared with the known data-product structure, while the
  per-block finite-sample term remains far below the 128-bit margin.
- The block size is a design parameter. A production deployment should fix it
  before data taking; the scan here is calibration evidence, not a post-hoc
  choice to be repeated per dataset.

## Limits

- The leftover-hash margin is 128 bits: `eps_LHL <= 2^-64`; the chained seed
  contributes `delta_seed = 2^-64` under the hybrid argument of the companion
  paper. The SHAKE-derived seed is computational, not an information-theoretic
  uniform string.
- The output bit files are not committed (~7.4 MB b=12, ~5.1 MB b=8, packed). Each
  manifest records the SHA256, block layout, and parameters; the files are
  regenerated by the commands in `README.md`.
- This is a Stage-2 demonstration. The release calendar, commitment integration,
  and production failure budget remain protocol engineering.

## Reproduction

```bash
python3 conditioning/toeplitz_extract.py --run-dir runG12 --b 12 \
    --hinf 11.3098 --block-events 25000 --seed-salt 0 \
    --out conditioning/out/b12-toeplitz-25k-s0.bits.bin \
    --manifest conditioning/out/b12-toeplitz-25k-s0.manifest.json
```

The STS reports are under `sts-2026-10-23/`; each directory carries the tool
report and the console log. The tool command is the standard NIST STS `assess`
sequence: input file → apply all tests → defaults → 58 sequences → binary input.
