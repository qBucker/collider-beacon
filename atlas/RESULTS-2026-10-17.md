# ATLAS cross-check of effect 1 — result (2026-10-17)

Sample: CERN Open Data record 93933 ("Run 2 2015+2016 proton-proton collision data
beta release, no skim"), CC0-1.0, DOI 10.7483/OPENDATA.ATLAS.VV3I.0WJE.
16/16 files processed; 50,000 entries read from the start of each file;
597,965 events with a passing leading jet; b = 8 (256 bins, 24.544 mrad).

## Result

Effect-1 band: bins 227-234, phi = +139.2..+150.5 deg (the same bins as the CMS measurement).

| Quantity | Value |
|---|---|
| Band count | 19,112 |
| Local ratio (sidebands +/-8 bins) | **1.0024 +/- 0.0072** (stat) |
| Statistical check | 0.0072 vs Poisson expectation 0.0073 (exact match) |
| ATLAS vs unity | 0.33 sigma |
| Local ratio, sidebands +/-4 / +/-16 / +/-32 | 0.9991 / 1.0033 / 1.0068 |
| Fourier-baseline ratio (K = 2..12) | 0.9988 - 1.0043 |
| CMS reference (global estimator) | 0.8947 (-10.5%); CMS local estimator 0.9475 |
| Tension with the CMS value | **14.1 sigma** (pooled; ATLAS local vs CMS global, CMS band-ratio uncertainty 0.0025 included; conservative) |
| Same-estimator cross-check | global-vs-global (ATLAS 1.0235) gives 16.9 sigma; local-vs-local gives 7.2 sigma |
| min-entropy (CP, Bonferroni) | 7.7148 bits/event (gate >= 6 passes) |
| chi-squared p | < 1e-300 (uniformity gate fails) |
| KS p | 4.1e-10 (uniformity gate fails) |
| Global band ratio (band vs all other bins) | 1.0235 |

The reported 14.1 sigma is the conservative comparison: the CMS -10.5% is defined with the
global estimator, while the ATLAS number quoted in the tension is the local-sideband
estimator (closer to the CMS value than the ATLAS global estimator). Same-estimator
comparisons are also reported; all exclude the CMS value.
The lower ATLAS min-entropy relative to CMS (7.7148 vs 7.8413) is the expected direction:
n is an order of magnitude smaller, and the broad acceptance modulation raises the maximum
bin count.

The band ratio is consistent with unity under every local baseline tested. No file shows
a deficit at the -10% level (per-file local ratios 0.954-1.052, spread consistent with
statistics).

## Interpretation

The localized acceptance deficit reported in CMS (bins 227-234, -10.5%) is absent in
ATLAS at the same azimuthal bins. With 597,965 events the band is measured to 0.72%;
the CMS value is excluded at 14.1 sigma (pooled, conservative estimator comparison;
same-estimator checks give 7.2-16.9 sigma). This supports the interpretation that the
effect is a CMS-specific detector/trigger acceptance feature, not a universal property
of the production process.

## Caveats (recorded, not hidden)

- The ATLAS "no skim" sample is trigger-selected, not minimum bias: 72% of events in
  the first 2,000 entries of data15_periodD contain at least one jet with pT > 20 GeV.
  The comparison relies on azimuthal symmetry of the trigger/selection; the local
  baseline methods above are insensitive to a smooth phi modulation.
- The full 256-bin distribution is not uniform (chi-squared and KS gates fail), as
  expected for a trigger-selected sample with broad acceptance modulation (global band
  ratio +2.4%). The effect-1 test is a localized-band test, evaluated against local
  sidebands and Fourier baselines.
- Sampling uses the first 50,000 entries of each file, not a random subsample;
  per-file counts are recorded in the manifest.
- ATLAS small-R jets: anti-kT R = 0.4, pT > 20 GeV, |eta| < 2.5 (ntuple preselection),
  the same leading-jet definition in form as the CMS analysis.
